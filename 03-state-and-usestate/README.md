# Concept 03: State & useState Hook ⚡

**State** represents a component's memory. When state changes, React re-renders the component to reflect the new data on the screen.

---

## 🔑 Key Concepts Covered

- **The useState Hook**: Initializing state and updating it via setter functions.
- **State Immutability**: Never mutating state directly; always providing new copies (using the spread operator ...).
- **Batching & Functional Updates**: Using setCount(prev => prev + 1) when new state depends on previous state.
- **Lifting State Up**: Sharing state between sibling components by moving it to their common parent.
