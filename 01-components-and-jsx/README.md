# Concept 01: Components & JSX 🧩

React applications are built from isolated, reusable pieces of UI called **Components**, written using **JSX** (JavaScript XML).

---

## 🔑 Key Concepts Covered

- **Functional Components**: Defining UI functions that return JSX.
- **JSX Syntax**: Writing HTML-like syntax within JavaScript.
- **JSX Rules**:
  - Return a single root element (or Fragment <>...</>).
  - Close all tags (<img />, <input />, <br />).
  - Use camelCase for attributes (className instead of class, htmlFor instead of or).
  - Embed JavaScript expressions inside curly braces {expression}.
