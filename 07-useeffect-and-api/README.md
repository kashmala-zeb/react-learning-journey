# Concept 07: useEffect & API Data Fetching 🌐

Managing side effects such as data fetching, timers, manual DOM updates, and subscriptions.

---

## 🔑 Key Concepts Covered

- **Dependency Array**:
  - []: Runs once when component mounts.
  - [dep1, dep2]: Runs on mount and when dependencies change.
  - No array: Runs on every render (rarely intended).
- **Cleanup Functions**: Preventing memory leaks (canceling requests, clearing setInterval).
- **API Fetching**: Using etch or xios with sync/await, loading states, and error handling.
