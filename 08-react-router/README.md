# Concept 08: React Router 🧭

Enabling multi-page navigation and deep linking in Single Page Applications (SPAs) without page reloads.

---

## 🔑 Key Concepts Covered

- **Core Components**: BrowserRouter, Routes, Route, Link, NavLink.
- **Dynamic Routing**: Route parameters (/users/:id) via useParams().
- **Programmatic Navigation**: Navigating via useNavigate().
- **Layouts & Nested Routes**: Using <Outlet /> for persistent headers and navigation bars.
