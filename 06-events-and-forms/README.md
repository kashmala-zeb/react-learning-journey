# Concept 06: Events & Controlled Forms 📝

Handling user interactions (clicks, keyboard input, form submissions) in React.

---

## 🔑 Key Concepts Covered

- **Synthetic Events**: React's cross-browser wrapper around the browser's native event system (onClick, onChange, onSubmit).
- **Controlled Components**: Binding form inputs (<input>, <textarea>, <select>) to component state via alue and onChange.
- **Form Submission**: Handling event.preventDefault() to stop full-page browser reloads.
- **Multiple Inputs**: Managing complex forms with a single state object.
