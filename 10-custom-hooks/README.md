# Concept 10: Custom Hooks 🎣

Extracting and reusing stateful component logic across multiple components.

---

## 🔑 Key Concepts Covered

- **Hook Rules**: Must start with use (e.g., useFetch, useLocalStorage, useWindowSize).
- **Composing Existing Hooks**: Combining useState, useEffect, and other built-in hooks into reusable utilities.
- **Clean Separation of Concerns**: Keeping UI presentation separate from business logic.
