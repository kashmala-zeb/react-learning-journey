# Concept 05: Lists & Keys 📋

Transforming arrays of data into elements using standard JavaScript methods like .map() and .filter().

---

## 🔑 Key Concepts Covered

- **Transforming Arrays**: Using data.map(item => <Item key={item.id} {...item} />).
- **The Importance of key**: Providing a stable, unique identity for each element so React knows which items changed, were added, or were removed.
- **Pitfall**: Avoid using the array index as a key when items can be reordered, inserted, or deleted.
