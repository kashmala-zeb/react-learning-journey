# Mini Project 01: Job Listing Cards 💼

A responsive job board card listing application built with **React** and **Vite**, demonstrating foundational React component communication through **props**.

---

## 🎯 Concepts Practiced

- **Functional Components**: Breaking down UI into a reusable `Card.jsx` component.
- **Passing Props**: Passing image URLs, company names, posting dates, job roles, salary rates, tags, and location data via props.
- **Lists & Keys**: Mapping an array of `jobOpenings` objects into dynamic card instances using `.map()`.
- **CSS Styling**: Custom CSS layout and interactive hover effects.

---

## 🚀 How to Run

1. Navigate to this directory:
   ```bash
   cd 02-props/01-job-listing-cards
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Run the development server:
   ```bash
   npm run dev
   ```
4. Open the local Vite URL (e.g., `http://localhost:5173`).
