# Concept 09: Context API (Global State) 🌐

Sharing data across the entire component tree without having to pass props down manually through every level (solving "prop drilling").

---

## 🔑 Key Concepts Covered

- **createContext**: Defining a shared context.
- **Context.Provider**: Wrapping components and supplying the shared state values and updater functions.
- **useContext Hook**: Consuming context data anywhere within the provider tree.
- **Common Use Cases**: Dark/Light theme, authenticated user session, shopping cart items.
